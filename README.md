# keen-photo.com

Site statique : HTML, CSS, deux images. Aucune dépendance, aucun build.

- `index.html` : page unique, quatre écrans.
- `mentions-legales/index.html` : placeholders entre crochets à remplir.
- `assets/` : feuille de style et images.

Déploiement : copier le contenu du dossier à la racine de n'importe quel hébergement web.
